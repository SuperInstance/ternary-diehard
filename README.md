# ternary-diehard

A Rust library implementing Game of Life variants (ThreeStateLife, HighLifeTernary, DayAndNightTernary) extended to ternary grids where every cell carries one of three states — Dead, Idle, or Alive — enabling richer transition dynamics than classical binary Life, including gradual birth/death buffering through the Idle intermediate state, oscillation detection, still-life analysis, and population statistics across generations.
